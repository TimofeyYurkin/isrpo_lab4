# Общее описание проекта

**Geometric Lib** - это библиотека, написанная на Python, реализующая функции для вычисления периметра и площади следующих геометрических фигур:

- Треугольник
- Квадрат
- Прямоугольник
- Окружность

Файловая структура проекта выглядит следующим образом:

```
geometric_lib/
    docs/
        README.md
    circle.py
    rectangle.py
    square.py
    triangle.py
```

Каждый файл в корневой директории содержит в себе функции для вычисления
площади и периметра соответствующей фигуры. 

Директория `docs` содержит документацию проекта.

## Используемые формулы

### Площадь

> [!NOTE]
> Для вычислений используется значение числа π с точностью 15 знаков после запятой

- Треугольник: S = ah / 2
- Квадрат: S = a²
- Прямоугольник: S = ab
- Окружность: S = πR²

### Периметер

- Треугольник: P = a + b + c
- Квадрат: P = 4a
- Прямоугольник: P = 2(a + b)
- Окружность: P = 2πR
  
# Описание реализованных функций

> [!WARNING]
> Все ниже описанные функции не имеют какой-либо валидации аргументов, поэтому
> если передать в них некорректные значения (например, `r = -3`), то функция
> вернёт результат вычислений.

## `triangle.py`

### `area`

Принимает длину основания `a` и длину высоты `h` к этому основанию, возвращает значение площади треугольника.

**Параметры:**

- `a (float)`: вещественное число, обозначающее длину основания треугольника
  
- `h (float)`: вещественное число, обозначающее длину высоты к основанию треугольника

**Возвращаемое значение:**

`triangle_area (float)`: вещественное число, обозначающее площадь прямоугольника
            
**Пример использования:**

```
>>> area(4, 2)
4
```

### `perimeter`

Принимает длины сторон треугольника `a`, `b` и `c`, возвращает значение периметра данного прямоугольника.

**Параметры:**

- `a (float):` вещественное число, обозначающее длину первой стороны треугольника
  
- `b (float):` вещественное число, обозначающее длину второй стороны треугольника
  
- `c (float):` вещественное число, обозначающее длину третьей стороны треугольника

**Возвращаемое значение:**

`triangle_perimeter (float):` вещественное число, обозначающее периметер треугольника

**Пример использования:**

```
>>> perimeter(3, 4, 5)
12
```
